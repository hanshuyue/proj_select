# 政企项目材料标准化与智能生成平台迭代记录

## V1.0.0（2026-09-17）

### 平台能力

- 完成用户认证、角色权限、菜单、部门、岗位、字典、参数及操作日志能力。
- 完成甄选结果项目管理、评审材料上传、PPT模板管理与PPT生成。
- 完成项目立项、附件、收益模式、招投标对比、PPT模板管理与PPT生成。
- 完成标准收支测算表和经济效益测算表，支持按选择模式生成配套表格。

### 本轮完善

- 平台正式命名为“政企项目材料标准化与智能生成平台”，部署标识统一为 `gems-platform`。
- 标准收支测算表增加“项目收入（万元）”“投资（万元）”“成本（万元）”合并分类列。
- 收益测算默认读取对应标准收支表的收入、投资和成本，并提供恢复默认值能力。
- 完善净利润、净利润率、净现值率、静态回收期、动态回收期等计算逻辑。
- 优化表格只读与可填写状态，减少不必要的底色干扰。
- 补齐部署、接口、数据库、技术设计、需求规格和测试文档。

### 发布注意事项

- 数据库脚本按基础库、甄选模块、立项模块顺序执行。
- 升级不得覆盖业务数据目录和已上传模板。
- 发布前必须执行前端构建、后端测试以及PPT导出回归测试。

## 后续规划

- 增加计算公式版本标识和公式审计记录。
- 增加模板兼容性自动检查报告。
- 增加项目材料生成任务状态和失败重试机制。
- 增加数据库迁移工具，替代手工执行增量SQL。

## V1.1.0（2026-09-18）

### 统一账号与强制改密

- 登录入口统一为中国大陆手机号，同时保留存量账号兼容查询，便于迁移期间平滑切换。
- 后台新增用户和管理员重置密码统一使用 `123456789`，并写入首次登录待改密标记。
- 自主注册用户使用本人设置的密码，不触发首次登录改密。
- 登录后待改密用户只能查看本人信息、修改密码或退出；前端强制跳转到独立改密页，后端同步拦截其他接口。
- 修改密码成功后清除待改密标记并要求重新登录。
- 每次携带令牌访问时重新校验账号启用状态，账号被禁用后现有会话立即失效。
- 增加 `must_change_password` 自动迁移与初始化脚本，兼容已有数据库升级。

### 成品PPT上传与管理员视图

- 甄选结果、项目立项列表增加“上传成品PPT”入口，上传文件自动关联业务类型、项目和上传人。
- 新增“材料管理 → 成品PPT记录”，管理员可查看全平台上传人、所属市县、关联项目、文件、时间和审核状态；普通用户仅查看本人记录。
- 超级管理员及管理员恢复完整后台侧边栏，修复业务菜单过滤误隐藏管理模块的问题。
- 修复协作菜单与甄选菜单 ID 冲突，并在启动时自动恢复既有菜单数据。
- 侧边栏分组字号由 14px 调整为 16px，菜单项由 13px 调整为 15px。
- 修正甄选结果下误显示“注册用户”的菜单污染，恢复为“PPT模板管理”。
- 立项填报页将“更换PPT模板（新窗口）”改为语义明确的“PPT模板管理”，并使用站内导航。
- 岗位精简为“项目负责人、材料填报人、审核人员”三类，升级时自动迁移既有岗位关联。
- 原“注册用户”页面调整为“管理员设置”；超级管理员可查看全平台非超管账号并直接设置或取消管理员身份，用户管理页增加明确入口。
