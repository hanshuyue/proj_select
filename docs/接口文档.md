# 政企项目材料标准化与智能生成平台接口文档

文档版本：V1.0  
基础路径：`/api`  
数据格式：`application/json; charset=UTF-8`

## 1. 通用约定

除登录、验证码和健康检查外，接口通过 `Authorization: Bearer <token>` 携带JWT。文件上传使用 `multipart/form-data`，文件下载返回二进制流。

通用响应结构：

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {}
}
```

常用状态：200成功、400参数或业务错误、401未登录、403无权限、404资源不存在、500服务异常。

## 6. 调用示例

```bash
curl -X POST 'http://127.0.0.1:18081/api/auth/login' \
  -H 'Content-Type: application/json' \
  -d '{"username":"admin","password":"******","captchaKey":"...","captchaCode":"..."}'
```

具体请求字段以控制器请求对象和 `/v3/api-docs` 生成结果为准；生产环境不建议直接暴露接口文档端点。
# V1.1 注册用户与文档中心接口

- `GET /api/public/departments`：公开获取可注册部门。
- `POST /api/auth/register`：实名注册并立即启用账户（无需登录）。
- `GET /api/admin/registrations`：管理员查看本市县注册结果；超级管理员查看全部结果。
- `PUT /api/admin/registrations/{id}/administrator`：仅超级管理员设置或取消业务管理员。
- `GET /api/documents`：普通用户查看本人文档；管理员查看全部文档。
- `POST /api/documents`：以 `multipart/form-data` 提交 `title`、`description`、`file`。
- `GET /api/documents/{id}/file`：下载有权访问的文档。
- `PUT /api/documents/{id}/feedback`：管理员提交点评及 `APPROVED` / `REVISION_REQUIRED` 结果。
