# 政企项目材料标准化与智能生成平台测试指南

文档版本：V1.0

## 1. 测试前准备

- 准备独立测试数据库及Redis，禁止连接生产库。
- 准备甄选PPT模板、立项PPT模板、标准收支工作簿和典型附件。
- 至少准备管理员、项目人员和只读审核人员三类账户。
- 记录当前版本号、数据库脚本版本和模板文件摘要。

## 2. 自动化检查

前端：

```bash
cd scaffold-vue
npm ci
npm run test:unit
npm run build
```

后端：

```bash
cd scaffold-system
mvn test
mvn -pl scaffold-admin -am clean package -DskipTests
```

## 3. 接口冒烟测试

```bash
curl -i http://127.0.0.1:18082/api/health
curl -I http://127.0.0.1:18081/
```

验证登录成功、错误密码、验证码错误、无令牌、过期令牌和无权限访问。上传接口需验证合法文件、错误类型、超限文件和重复模板。

## 4. 核心业务测试

### 甄选结果

1. 新增项目并保存投标方信息。
2. 上传并下载评审材料，核对文件摘要。
3. 切换默认模板并生成PPT。
4. 验证默认模板不可删除，非默认模板可删除。

### 项目立项

1. 新增项目并填写所有基础数据。
2. 分别选择和取消收益模式，核对联动表格。
3. 填写标准收支表，检查收入、投资和成本小计。
4. 核对每种模式的经济效益表默认值来自其上方对应收支表。
5. 删除默认收入或成本后点击恢复，确认重新读取最新汇总。
6. 填写模板规定样例，逐项核对利润、净利润率、现金流、净现值率和回收期。
7. 生成PPT，检查页面数量、表格合并、字体、边框和数值精度。
8. 双击嵌入工作簿，核对完整输入精度和公式结果。

## 5. 财务边界测试

- 收入、成本、投资全部为零。
- 收入为零且成本不为零，确认无除零异常。
- 现金流始终为负或始终为正，确认IRR显示不可计算。
- 项目期短于和长于折旧年限，核对项目期后折旧延续。
- 小数位较多、负数、极大金额和税率边界。
- 修改上方标准收支表后恢复测算值，确认使用最新数据而非旧默认值。

## 6. 权限与安全测试

- 普通用户不得进入无权限菜单或直接调用接口。
- 文件名包含 `../`、绝对路径或隐藏文件时必须被拒绝或安全改名。
- `/api/` 以外仅允许读取静态资源。
- MySQL、Redis和Java后端端口不得从公网连接。
- 日志不得记录数据库密码、JWT密钥和用户明文密码。

## 7. 发布验收

- 前后端构建成功且自动化测试通过。
- Nginx配置通过 `nginx -t`。
- `gems-platform.service` 状态为 active。
- 登录、保存、上传、下载、计算和PPT导出全部通过。
- 重启应用后数据、模板、附件保持完整。
- 已完成数据库与数据目录备份，并验证回滚包可用。
