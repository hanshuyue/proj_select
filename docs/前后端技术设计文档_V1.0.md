# 政企项目材料标准化与智能生成平台前后端技术设计文档

文档版本：V1.0  
日期：2026-09-17

## 1. 技术架构

平台采用前后端分离架构。浏览器访问 Nginx；静态资源由 Nginx 提供，`/api/` 转发至 Spring Boot；后端访问 MySQL、Redis和持久化文件目录。

| 层次 | 技术 |
|---|---|
| 前端 | Vue 3、TypeScript、Vite、Vue Router、Element Plus |
| 后端 | Java 17、Spring Boot 3、MyBatis-Plus、Spring Security、JWT |
| 工作流 | Flowable |
| 文档处理 | Apache POI（PPTX/XLSX） |
| 数据 | MySQL 8、Redis |
| 部署 | Nginx、systemd、Ubuntu 22.04 |

## 2. 前端设计

- `src/views/`：登录、系统管理、甄选结果、项目立项等页面。
- `src/components/finance/`：标准收支和经济效益测算组件。
- `src/api/`：按业务域封装接口，生产环境默认使用同源 `/api`。
- `src/router/`：路由及登录态访问控制。
- 可编辑值和公式值由组件状态区分；公式结果不允许直接编辑。
- 每个收益模式拥有独立的标准收支表和经济效益测算表，恢复按钮重新读取该模式对应的收支汇总。

## 3. 后端设计

- `scaffold-admin`：启动模块、健康检查和运行配置。
- `scaffold-system`：认证、系统管理、甄选、立项及PPT生成。
- `scaffold-framework`：安全、审计、异常处理和数据权限。
- `scaffold-workflow`：流程模型、部署、任务和审批轨迹。
- `scaffold-generator`：数据库表导入和代码生成。
- `scaffold-common`：统一返回、分页和通用异常。

统一入口为 `/api`；权限由JWT身份、菜单权限标识和方法级权限共同控制。业务异常转换为统一响应，不向前端暴露堆栈。

## 4. 文档生成设计

- 模板分为甄选和立项两类，各自维护默认模板。
- 上传时校验文件类型和模板结构；默认模板不可直接删除。
- 立项收益模式决定生成哪些收益分析页面及附表。
- PPT展示值按模板格式输出，嵌入Excel工作簿保留计算所需精度。
- 动态表格需处理行插入、单元格合并、字体、边框及分页溢出。
- 生成失败不得覆盖模板源文件，临时文件完成后及时清理。

## 5. 财务计算设计

计算链路为：标准收支明细 → 收入/投资/成本汇总 → 年度现金流 → 利润和所得税 → 净现金流 → 折现指标及回收期。前端用于实时反馈，后端负责保存、校验和输出，关键公式必须保持一致。

边界规则：收入为零时收益率不做除零；无符号变化时IRR返回不可计算；回收期仅在累计现金流跨越零点时计算；折旧按资产分类年限延续至项目期后。

## 6. 安全设计

- 密码不以明文保存，生产密钥仅通过环境文件注入。
- Java、MySQL、Redis只监听本机；公网仅开放Nginx端口。
- 上传限制类型、大小、文件名与保存路径，禁止目录穿越。
- 下载接口执行身份和业务权限校验。
- 操作日志记录关键增删改、模板及PPT导出行为。

## 7. 非功能设计

- 典型查询响应目标小于2秒；大型PPT生成允许长任务响应。
- 前端资源启用压缩和指纹缓存，HTML禁止长期缓存。
- 后端服务异常自动重启；业务数据目录与程序版本分离。
- 日志、数据库和附件纳入备份，发布包支持快速回滚。
