# 服务器部署说明（已归档）

本文档为旧目录方案，现行部署规范请以 [部署文档.md](./部署文档.md) 为准。正式系统名称为“政企项目材料标准化与智能生成平台”，部署标识为 `gems-platform`，部署根目录为 `/home/glory/gems-platform`。

本系统由 Vue 前端、Spring Boot 后端、MySQL 和 Redis 组成。项目立项与甄选结果的 PPT 模板、收支明细工作簿及上传附件都保存在后端的数据目录，部署和升级时必须保留该目录。

## 服务器准备

- Linux（建议 Ubuntu 22.04 / Rocky Linux 9）、JDK 21、MySQL 8、Redis 7、Nginx。
- 建议目录为 `/opt/scaffold`，其中 `data/` 使用持久化磁盘。
- 数据库先按现有环境导入结构与业务数据；不要使用开发机数据库账号和密码。

## 构建与上传

```bash
cd scaffold-vue && npm ci && npm run build
cd ../scaffold-system && mvn -pl scaffold-admin -am clean package -DskipTests
```

上传：`scaffold-admin-0.1.0-SNAPSHOT.jar` 到 `/opt/scaffold/app.jar`，`scaffold-vue/dist/` 到 `/opt/scaffold/web/`，以及 `scaffold-admin/data/` 到 `/opt/scaffold/data/`。

`data/selection/templates/` 与 `data/initiation/templates/` 分别存放两类标准 PPTX。项目立项模板内的收支明细工作簿会随 PPTX 一并保存，无需另行部署 Excel。

## 后端启动

创建权限为 `600` 的 `/etc/scaffold/scaffold.env`：

```bash
DB_URL='jdbc:mysql://127.0.0.1:3306/scaffold_system?useUnicode=true&characterEncoding=utf8&useSSL=false&serverTimezone=Asia/Shanghai'
DB_USERNAME='scaffold'
DB_PASSWORD='替换为数据库密码'
REDIS_HOST='127.0.0.1'
REDIS_PORT='6379'
REDIS_PASSWORD=''
JWT_SECRET='替换为不少于32字符的随机密钥'
SERVER_PORT='8080'
SELECTION_STORAGE_PATH='/opt/scaffold/data/selection'
INITIATION_STORAGE_PATH='/opt/scaffold/data/initiation'
SELECTION_BOOTSTRAP_TEMPLATE_PATH='/opt/scaffold/data/selection/templates/standard.pptx'
INITIATION_BOOTSTRAP_TEMPLATE_PATH='/opt/scaffold/data/initiation/templates/standard.pptx'
```

创建 `/etc/systemd/system/scaffold.service`：

```ini
[Unit]
Description=Scaffold PPT service
After=network.target mysql.service redis.service

[Service]
Type=simple
User=scaffold
WorkingDirectory=/opt/scaffold
EnvironmentFile=/etc/scaffold/scaffold.env
ExecStart=/usr/bin/java -jar /opt/scaffold/app.jar --spring.profiles.active=prod
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now scaffold
sudo systemctl status scaffold
```

## Nginx

站点根目录设置为 `/opt/scaffold/web`；将 `/api/` 转发至 `127.0.0.1:8080`。示例：

```nginx
server {
  listen 80;
  server_name example.com;
  root /opt/scaffold/web;
  client_max_body_size 100m;

  location /api/ {
    proxy_pass http://127.0.0.1:8080;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
  }
  location / { try_files $uri $uri/ /index.html; }
}
```

## 验收与升级

1. 登录后左侧只显示“甄选结果”和“项目立项”。
2. 两个模块的“PPT 模板管理”都支持上传、下载、设默认、删除；默认模板不能删除。
3. 新建立项并填写收支明细，导出 PPT 验证展示数值为两位小数；双击嵌入工作簿可查看完整输入精度。
4. 升级前备份数据库与 `/opt/scaffold/data`；替换 `app.jar`、`web/` 后重启服务，切勿覆盖 `data/`。
