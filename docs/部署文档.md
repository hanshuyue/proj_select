# 政企项目材料标准化与智能生成平台部署文档

文档版本：V1.0  
更新日期：2026-09-17  
系统标识：`gems-platform`

## 1. 部署架构

平台由 Vue 3 前端、Spring Boot 后端、MySQL 8、Redis 和 Nginx 组成。Nginx 对外提供站点并转发 `/api/`，Java、MySQL、Redis 仅监听本机地址。

| 服务 | 端口 | 对外开放 |
|---|---:|---|
| Nginx 网站 | 18081 | 是 |
| Java 后端 | 18082 | 否 |
| 项目 MySQL | 13316 | 否 |
| 项目 Redis | 16389 | 否 |

禁止停止或修改现有 `expense-mysql.service`（13306）和 `expense-redis.service`（16379），禁止覆盖 `/etc/nginx/nginx.conf`。

## 2. 目录规范

```text
/home/glory/gems-platform/
├── app/gems-platform-server.jar
├── web/
├── build/base_test1/
├── releases/
├── data/
│   ├── initiation/
│   └── selection/
└── logs/
```

运行时继续使用 `/srv/scaffold/runtime/`，数据库和 Redis 数据继续使用 `/srv/scaffold/mysql`、`/srv/scaffold/redis`。`data/` 为持久化业务目录，升级时不得覆盖。

## 3. 构建发布

```bash
source /etc/profile.d/scaffold-runtime.sh

cd /home/glory/gems-platform/build/base_test1/scaffold-vue
npm ci
npm run build

cd /home/glory/gems-platform/build/base_test1/scaffold-system
mvn -pl scaffold-admin -am clean package -DskipTests

install -o glory -g glory -m 0644 \
  scaffold-admin/target/gems-platform-server.jar \
  /home/glory/gems-platform/app/gems-platform-server.jar

rsync -a --delete \
  /home/glory/gems-platform/build/base_test1/scaffold-vue/dist/ \
  /home/glory/gems-platform/web/
```

首次部署时复制 `data/`；后续升级不得使用 `--delete` 同步该目录。

## 4. 后端配置

`/etc/gems-platform/gems-platform.env` 权限必须为 `600`：

```ini
DB_URL=jdbc:mysql://127.0.0.1:13316/gems_platform?useUnicode=true&characterEncoding=utf8&useSSL=false&serverTimezone=Asia/Shanghai
DB_USERNAME=gems_app
DB_PASSWORD=替换为数据库密码
REDIS_HOST=127.0.0.1
REDIS_PORT=16389
REDIS_PASSWORD=替换为Redis密码
JWT_SECRET=替换为至少32字符的随机密钥
SERVER_PORT=18082
SELECTION_STORAGE_PATH=/home/glory/gems-platform/data/selection
INITIATION_STORAGE_PATH=/home/glory/gems-platform/data/initiation
SELECTION_BOOTSTRAP_TEMPLATE_PATH=/home/glory/gems-platform/data/selection/templates/standard.pptx
INITIATION_BOOTSTRAP_TEMPLATE_PATH=/home/glory/gems-platform/data/initiation/templates/standard.pptx
```

## 5. systemd服务

`/etc/systemd/system/gems-platform.service`：

```ini
[Unit]
Description=GEMS Platform Backend Service
After=network.target gems-mysql.service gems-redis.service
Requires=gems-mysql.service gems-redis.service

[Service]
Type=simple
User=glory
Group=glory
WorkingDirectory=/home/glory/gems-platform/app
EnvironmentFile=/etc/gems-platform/gems-platform.env
ExecStart=/srv/scaffold/runtime/java-17/bin/java -jar /home/glory/gems-platform/app/gems-platform-server.jar --spring.profiles.active=prod
Restart=always
RestartSec=5
SuccessExitStatus=143
StandardOutput=append:/home/glory/gems-platform/logs/backend.log
StandardError=append:/home/glory/gems-platform/logs/backend-error.log
NoNewPrivileges=true
PrivateTmp=true

[Install]
WantedBy=multi-user.target
```

## 6. Nginx站点

新建 `/etc/nginx/sites-available/gems-platform`，不要覆盖主配置：

```nginx
server {
    listen 18081;
    listen [::]:18081;
    server_name _;
    root /home/glory/gems-platform/web;
    index index.html;
    client_max_body_size 100m;
    send_timeout 300s;

    gzip on;
    gzip_vary on;
    gzip_min_length 1024;
    gzip_types text/plain text/css application/javascript application/json image/svg+xml font/ttf;

    location /api/ {
        proxy_pass http://127.0.0.1:18082;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_connect_timeout 10s;
        proxy_send_timeout 300s;
        proxy_read_timeout 300s;
        proxy_request_buffering off;
    }

    location /assets/ {
        expires 30d;
        add_header Cache-Control "public, immutable";
        try_files $uri =404;
    }

    location / {
        try_files $uri $uri/ /index.html;
        add_header Cache-Control "no-cache";
    }

    location ~ /\. { deny all; }
    access_log /home/glory/gems-platform/logs/nginx-access.log;
    error_log /home/glory/gems-platform/logs/nginx-error.log warn;
}
```

授权 Nginx 读取静态目录：

```bash
sudo setfacl -m u:www-data:x /home/glory
sudo setfacl -R -m u:www-data:rX /home/glory/gems-platform/web
sudo setfacl -R -d -m u:www-data:rX /home/glory/gems-platform/web
sudo ln -s /etc/nginx/sites-available/gems-platform /etc/nginx/sites-enabled/gems-platform
sudo nginx -t && sudo systemctl reload nginx
```

## 7. 启动与验收

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now gems-platform
sudo systemctl status gems-platform
curl -i http://127.0.0.1:18082/api/health
curl -I http://127.0.0.1:18081/
```

最终地址：`http://服务器IP:18081/`。仅对外开放 18081。

## 8. 升级与回滚

升级前备份数据库和 `/home/glory/gems-platform/data`。发布包按时间保存到 `releases/YYYYMMDD-HHmm/`；替换 JAR 与前端后重启 `gems-platform.service`。失败时恢复上一版本 JAR、前端目录并重启，业务数据目录不得随版本回滚而覆盖。
# V1.1 配置补充

生产环境应设置 `DOCUMENT_STORAGE_PATH` 指向持久化且定期备份的目录，并确保运行账户具备读写权限。升级已有数据库时执行 `scaffold-system/sql/user_document_module.sql`；全新初始化时该脚本会在基础脚本后自动执行。
